# Full Stack Open Exercises

This repository contains my solutions for the [Full Stack Open](https://fullstackopen.com/en/) course.  
Exercises are organized by parts, and each exercise has its own file or folder.

## Structure

fullstackopen-exercises/
├─ part0/ # Fundamentals of Web apps (diagrams with Mermaid)
├─ part1/ # React basics
├─ part2/ # Communicating with server
├─ part3/ # Programming a server with NodeJS and Express
└─ ...

## How to view diagrams

All diagrams are written using [Mermaid](https://mermaid-js.github.io/).  
GitHub renders Mermaid diagrams automatically inside `.md` files, allowing you to view them directly here in the repository.
